Integrity is not trust. SRI confirms that loaded bytes match this token. It does not guarantee that the source code is safe or that the original content was trustworthy.

🔒 Browser-local by default

File and text content never leave your device. URL mode makes a request directly from your browser to the chosen host, without sending credentials.

🌐 Remote URL limitations

Only HTTPS URLs are accepted. CORS must allow the browser to read the resource, and HTTP redirects are blocked. For other URLs, download the file and hash it locally.

📌 Pin a specific version

Use versioned, immutable resource URLs whenever possible. Browser-specific or changing assets may not match the hash at a later time.
